# StitchShift 👕

**StitchShift** adalah aplikasi web asisten *mix and match* pakaian personal dan pelacak target belanja fashion. Pengguna dapat memasukkan preferensi gaya (vibe, kategori, tipe cutting), mendapatkan rekomendasi set outfit, serta melacak progres pembelian item melalui sistem checklist yang terhubung dengan referensi katalog e-commerce.

## ✨ Fitur Utama
- **Modul Preferensi Pengguna** — form untuk memilih vibe, kategori pakaian, tipe cutting/shape, dan referensi visual.
- **Mesin Rekomendasi Outfit** — mencocokkan preferensi dengan tag outfit untuk menampilkan satu set outfit yang harmonis.
- **Integrasi Katalog E-Commerce (Mock Tier System)** — referensi produk dari brand internasional (*Higher Tier*: Zara, Uniqlo, Levi's) dan platform lokal (*Casual Tier*: Tokopedia, Shopee, TikTokShop).
- **Purchase Target & Progress Tracker** — checklist interaktif untuk menandai item yang sudah dimiliki (owned) vs yang masih perlu dibeli.

## 🎨 Konsep Desain
Modern Editorial / High-Fashion Minimalist — terinspirasi dari lookbook majalah fashion digital, dengan whitespace luas, grid asimetris, perpaduan font Serif & Sans-Serif, dan palet monokromatik (akan diterapkan mulai Minggu 3 dengan CSS/Tailwind).

## 📄 Struktur Halaman
| Halaman | Deskripsi |
|---|---|
| `index.html` | Daftar rekomendasi outfit (tabel) |
| `preferensi.html` | Form input preferensi gaya pengguna |
| `detail.html` | Detail set outfit + purchase tracker |
